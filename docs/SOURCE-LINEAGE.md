# Source lineage

WOIA Software v0.5.0 is an extract-and-recompose migration from:

- `Turpial-AI-Academy/asps-agent-plugin` at ASPS 2.6.0 / source commit `d2d9afaa223daf468047cf89ed273b4889c89f78`;
- the Software provider repositories selected by that ASPS baseline;
- WOIA Core for generic Project/runtime mechanics.

Generic ASPS control-plane mechanics moved to `woia-core`; Software-specific 23 phases, contracts, profiles, Release Hygiene and auxiliary triggers remain here.

The legacy ASPS repository/version history is not rewritten or downgraded.
