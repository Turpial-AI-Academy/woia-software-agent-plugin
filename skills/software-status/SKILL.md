# WOIA Software Status

Read current Project/Core state and software methodology state. Report:

- current objective/task when relevant;
- selected profile seed;
- completed/satisfied phases;
- next active responsibility;
- blockers and exact recovery;
- Release Hygiene/candidate status;
- pending human decision, if any.

Do not rerun provider inventory, install planning, or role materialization merely to answer status. Diagnose Core readiness only when state is inconsistent or the user asks for diagnostics.
